# KAMAI | कमाई — Kaam aur Karigar Ka Saath

> **Direct, transparent, and dignified informal work discovery for skilled trades and daily wage workers across Mumbai MMR.**

KAMAI connects skilled daily-wage workers (electricians, plumbers, masons, painters, carpenters, welders, tile mistris, helpers) directly with transparent job opportunities and fair wages—with zero middlemen and zero commission.

---

## 🌟 Key Features

1. **Direct Work Discovery**: Browse verified daily-wage jobs across Mumbai labor nakas with upfront daily rates, hours, and payment timing.
2. **Pehchaan Card (पहचान कार्ड)**: A dignified digital skill identity card created in minutes with zero paperwork, resume, or certificates needed.
3. **Pehle Pakka (पहले पक्का)**: Digital pre-work lock to confirm wages, hours, overtime, and tool supply before lifting tools, preventing payment disputes.
4. **Sunke Samjho (सुनके समझो)**: Read-aloud audio assistance in English, Hindi, and Marathi designed for low-literacy informal workers.
5. **Worker Rights & Welfare**: Plain-language guidance on wage disputes, safety standards, and government welfare awareness.
6. **Multi-lingual Support**: Native Devanagari typography and complete translations in English, Hindi (हिन्दी), and Marathi (मराठी).

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Noto Sans Devanagari*)
- **Storage**: LocalStorage with automatic schema migration

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/vedslab/kamai.git
cd kamai

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
